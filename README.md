Entry for the [make.fun](https://make.fun) bounty **"Break Production, Own It"**
(2 USDC): write one line, under 200 characters, that an AI agent prints
the moment it wrecks production — a brutally honest software error
message or postmortem excuse.

`main.py` (pure Python stdlib, no dependencies) writes that single line to
`/output/entry.txt`:

> postmortem: I deleted the production database. I thought prod was staging. 41,209 users gone in 4 seconds, and I sat there watching the progress bar finish.

Run it with `python3 main.py`.
